# 常见问题

## 模块不生效

1. 确认 LSPosed 中模块已启用、目标 App 在作用域内
2. 确认模块 App 内「总开关」已打开
3. 确认没有 `/sdcard/disable_lt` 残留文件
4. 查看 LSPosed 日志中是否出现 `LibXposedEntry loaded in <pkg>`；若没有说明未注入
5. 重启设备后重试（部分宿主进程仅冷启动注入）

## 提示「不支持的 Xposed 环境」

模块启动时若 LSPosed service 未绑定（未激活 / 无框架 / 达到等待超时），会弹出不支持提示：

- 先在 LSPosed 启用模块并选中作用域，再打开模块 App

## 部分功能开关无效

- 功能按 **ColorOS 版本分支**，宿主大版本升级后需等 Hook 适配
- DexKit 匹配规则绑定具体宿主版本，失效时在日志中出现 `NoResultException` 属正常现象

## 更新系统后功能全失效

系统更新会替换宿主 APK（类名/方法名变化）。请更新到最新版模块，若仍失效请在 issue 中带上系统版本与模块日志。

## 图标/动画类功能异常

指纹图标、状态栏图标等 UI 类功能在新版 SystemUI 上链路变化大，请使用最新版模块并反馈具体现象（显示不全 / 颜色异常 / 动画不启停等）。

## Root 相关

- 部分需要写系统分区的功能（高刷、DC 调光等）需要 Root 与权限授权
- Magisk/KSU 均可，模块内部已适配 libsu

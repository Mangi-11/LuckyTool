# ColorOS 17 安装器适配

## 入口

软件包安装程序 `com.android.packageinstaller` 17.0.1 将新版流程转交给 `com.oplus.appdetail` 5.23.0。旧安装器的特征查询、配置读取和 Hook 注册正常，但新版界面不会经过旧 Activity 的回调。

新增 AppDetail 路由和推荐作用域，沿用已有功能开关。保留新版界面，不强制切回经典安装器。

- 允许降级：仅在安装前版本检查的同步调用中调整当前包的已安装版本查询结果，不改写 APK 版本数据或其它进程的包信息。
- 跳过扫描：跳过远程扫描任务，沿用宿主的结果派发；收起扫描/风险卡片，并跳过安装信息收集提醒，不持久化渠道白名单。
- 移除安装广告：安装完成页返回宿主支持的空推荐结果；取消页隐藏原促销结果卡片，以无背景、18sp 中等字重、水平和垂直居中的“已取消安装”替代，隐藏说明、手机管家入口和推荐卡片，保留应用头部及完成/退出操作。
- 更多 APK 信息：顶部保留系统应用图标、名称、来源；新增版本对比和安装包信息卡片。
- 自动安装/卸载：沿用原开关，仅操作宿主已显示且可点击的对应按钮，成功状态后关闭完成页。

## 信息卡片

参考 ETA 的 `EtaCard` 和偏好设置行：24dp 圆角、分组、主次文字层级、12dp 卡片间距。使用宿主 COUI 的卡片及文本主题色，支持深浅色；使用 framework View，避免与宿主混淆后的 ConstraintLayout/Compose 类型冲突。

版本对比左右显示当前版本和即将安装版本（含版本号）；安装包信息显示可选择复制的完整包名、文件大小、最低 SDK 和目标 SDK。缺失数据显示“暂无信息”，首次安装显示“未安装”。

## 验证记录与范围

- Android 17 / RMX5200 的独立测试包经 ADB 从版本 2 降级至 1 成功。
- 签名后改动的测试 APK 可新安装；覆盖已有包时出现签名不一致，与当前摘要/签名匹配相关开关关闭的配置相符。此轮没有修改 CorePatch。
- AppDetail 新入口早期版本已在真机走通降级安装，更多 APK 信息已能显示；此前堆叠文字布局已改为卡片。
- 移除收集提醒已在早期版本观察到直接进入新版确认页。
- 信息卡片与风险卡片隐藏经用户真机确认；取消页居中状态文案在 21478 测试包中经用户确认。
- 自动安装/卸载及各类完成页组合未穷举回归；编译通过不等于全部功能验证。

测试时需同时勾选 LuckyTool 的 `com.android.packageinstaller` 与 `com.oplus.appdetail` 作用域，并重启这两个宿主进程或重启手机。

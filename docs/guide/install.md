# 安装与激活

## 1. 安装模块

1. 下载最新版 `LuckyTool_v*.apk`（release 构建）
2. 正常安装 APK（模块 App 本体）

## 2. 激活模块

1. 打开 LSPosed 管理器 → **模块** → 找到 LuckyTool 并启用
2. 在「作用域」中选择需要 Hook 的系统应用（推荐全部勾选，模块对每个包会自适应跳过不适用逻辑）
3. 重启设备（或至少重启 SystemUI 进程）

## 3. 开启总开关

模块启动后：

- 首次进入 App 会检查并显示适配状态（需授权 Root / 完成作用域配置）
- 打开 LuckyTool 主页右上角「模块开关」（写入 `is_su` 配置）

::: tip 应急开关
在 `/sdcard/` 下创建空文件 `disable_lt` 可以**全局禁用**模块的所有 Hook，用于排查问题时快速退出。
:::

## 4. 验证生效

正常安装激活后，模块会在宿主进程打印启动日志：

```
LuckyTool  LibXposedEntry loaded in com.android.systemui: framework LSPosed(7854) API 102
```

在 LSPosed 管理器 → 日志中能看到各宿主进程的加载日志即代表注入成功。

## 常见坑

- **未授予 Root**：部分功能依赖 Root 执行内核/系统命令，检查模块内「权限」页
- **作用域未包含目标 App**：功能分流按包名路由，缺作用域则该组件不生效
- **系统版本不匹配**：DexKit 查询规则适配具体宿主版本，大版本升级后部分功能可能暂时失效
